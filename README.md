# Contact Inbox

WordPress のお問い合わせフォームと受信一覧のプラグインです。フォームを管理画面で作ってページに置き、送られた内容を一覧で見て、そのまま返信できます。

## できること

| 場所 | できること |
| --- | --- |
| フォームの編集 | フォームの追加・複製・削除。項目（1行テキスト・メール・電話・URL・スラッグ・複数行・プルダウン・ラジオ・チェックボックス）の必須・文字数・選択肢・並び順。1行テキストと複数行は「くり返し」にすると、送る人が「＋ 追加」で欄を増やせます（参考 URL を複数書いてもらうときなど）。送信先・送信元・送信後のメッセージ |
| ページ | ブロック「フォーム」を置いて、フォームを選ぶ（エディタでも実際の見た目が出ます）。ショートコード `[donnma_form id="contact"]` も使えます |
| 受信一覧 | 未読・既読・返信済みの表示と絞り込み、本文の検索、フォームでの絞り込み、CSV 書き出し（Excel でそのまま開けます） |
| 1件の画面 | 内容の確認、管理画面からの返信（ひな形と元の問い合わせの引用つき）、返信の履歴、迷惑メールの切り替え |

- 送られた内容はメールでも届きます。送信者のメールアドレスは返信先（Reply-To）に入ります
- [Discord Post Notify](https://github.com/donnma777/discord-post-notify) が入っていれば、Discord にも通知します
- WordPress の「ツール → 個人データのエクスポート／消去」に対応しています（送信者のメールアドレスで受信を探します）。「設定 → プライバシー」のポリシーガイドに文例も出します
- Xserver では、管理画面から送った返信を、送信元アドレスのメールボックスの「送信済み」にも保存します。IMAP でつないだメールソフトから、そのままやり取りを続けられます

## 迷惑メール対策

- 人には見えない入力欄（ハニーポット）と、表示から送信までの秒数で、ロボットの送信を捨てます
- [Akismet](https://wordpress.org/plugins/akismet/) が有効なら、迷惑メールの判定に使います。判定されたものは受信一覧の「迷惑メール」に残り、30日で消えます
- 同じ IP からは10分に5回までしか送れません（迷惑メールと判定された送信も数えます）
- 1つの項目は5万文字までです（項目の文字数の上限を空にしたときも）

## インストール

1. [Releases](https://github.com/donnma777/wp-contact-inbox/releases) から Source code (zip) をダウンロード
2. WordPress の管理画面「プラグイン → 新規追加 → プラグインのアップロード」で zip を選び、有効化
3. 管理画面の「お問い合わせ → フォームの編集」でフォームを確かめ、ページにブロック「フォーム」を置く

有効にすると「お問い合わせ」フォーム（名前・メール・本文）が1つ入ります。送信先は空（管理者のメールアドレス）です。

## 動作環境

- WordPress 6.3 以上
- PHP 7.4 以上

## 注意

- 送信者への自動返信はありません。送信先のメールアドレスにサーバーの自動応答を設定すると、送信者に届きます（送信者のアドレスがない送信には、自動応答が返らない印を付けます）
- 添付ファイルは受け付けません
- Jetpack（Jetpack Social など）が入っていても、受信の中身は Jetpack の同期で WordPress.com に送りません
- 送信済みフォルダへの保存は、Xserver のメールボックスの置き場所を前提にしています。ほかのサーバーでは保存しません（返信は送れます）
- 管理画面は日本語のみです
- 個人で作ったものです。サポートや不具合対応のお約束はできません
